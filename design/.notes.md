## Quick answer

Use `c3c init` with the `--template static-lib` option to create a library-oriented project structure, then configure your target name in `project.json` to match your short lib name (`mtk`) while keeping the repo/project name as `matryoshka-3tk`. [c3-lang](https://c3-lang.org/build-your-project/build-commands/)

```bash
cd matryoshka-3tk
c3c init matryoshka-3tk --template static-lib
```

This gives you a ready-made static-lib layout with `src/`, `lib/`, `test/`, `project.json`, etc. [c3-lang](https://c3-lang.org/build-your-project/build-commands/)

## Recommended layout for `matryoshka-3tk` (lib name `mtk`)

After running the command above, you’ll have something like:

```text
matryoshka-3tk/
├─ build/
├─ docs/
├─ lib/
├─ resources/
├─ scripts/
├─ src/
│  └─ mtk.c3          # or main.c3 → rename to mtk.c3 and adjust project.json
├─ test/
├─ LICENSE
├─ project.json
└─ README.md
```

Inside `project.json`, define a target whose name is `mtk` and set its `type` to `"static-lib"`: [c3-lang](https://c3-lang.org/build-your-project/project-config/)

```jsonc
{
  "langrev": "1",
  "warnings": ["no-unused"],
  "dependency-search-paths": ["lib"],
  "dependencies": [],
  "authors": ["Your Name <you@example.com>"],
  "version": "0.1.0",
  "sources": ["src/**"],
  "output": "../build",

  "targets": {
    "mtk": {
      "type": "static-lib",
      // optional: "target": "linux-x64",
      // optional overrides here
    }
  },

  // global defaults (opt, safe, etc.)
  "opt": "O0",
  "safe": true,
  "use-stdlib": true
}
```

Key points:

- Repo / top-level project name: `matryoshka-3tk` (directory and Git remote).
- Internal static lib target name: `mtk` (used in `project.json` and when building).
- Build commands from inside `matryoshka-3tk`:
  - `c3c build mtk` – build the static library target.
  - `c3c run mtk` – if you later add a test/exe target that links against it.
  - `c3c test` – run tests defined with `@test` in your `sources`/`test-sources`. [c3-lang](https://c3-lang.org/build-your-project/build-commands/)

## If you already have the repo

If `matryoshka-3tk` already exists with content:

1. Create a subdirectory for the C3 project (optional but clean), e.g.:

   ```bash
   cd matryoshka-3tk
   mkdir c3
   cd c3
   c3c init matryoshka-3tk --template static-lib
   ```

2. Or, initialize directly in the repo root:

   ```bash
   cd matryoshka-3tk
   c3c init . --template static-lib - wrong!!!
   ```
  ```bash
  c3c init mtk --template static-lib
  ```

  move content of mtk up/remove mtk/fix project.json

   Then edit `project.json` to set the target name to `mtk` as shown above. [c3-lang](https://c3-lang.org/build-your-project/build-commands/)

## Source/module naming

Inside `src/mtk.c3`, start with:

```c3
module mtk;

// public API here
```

Module names must be lowercase and can use `_`, matching your `mtk` lib name. [c3-lang](https://c3-lang.org/language-fundamentals/naming/)
